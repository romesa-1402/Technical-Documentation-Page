Introduction

This documentation provides a beginner-friendly overview of HTML and CSS, the two core building blocks of every website.

HTML (HyperText Markup Language) structures the content of a page, while CSS (Cascading Style Sheets) controls how that content looks.

By the end of this guide, you should understand the basic syntax, common terms, and how the two languages work together.

  • Understand the purpose of HTML
  • Understand the purpose of CSS
What is HTML

HTML stands for HyperText Markup Language. It is the standard language used to create the structure of web pages using elements called tags.

Every HTML document starts with a doctype declaration, followed by an <html> element that wraps the entire page.

Below is a simple example of an HTML element:

<h1>Hello World</h1>

Tags usually come in pairs: an opening tag and a closing tag, with content placed in between.

  • Tags define structure
  • Attributes add extra information
  • Elements can be nested inside other elements
What is CSS

CSS stands for Cascading Style Sheets. It is used to style and lay out HTML elements, including colors, fonts, spacing, and positioning.

CSS rules are made up of a selector and a declaration block, as shown in the example below:

h1 { color: blue; font-size: 24px; }

CSS can be added inline, internally within a <style> tag, or externally through a linked stylesheet file.

  • Selectors target HTML elements
  • Properties define what to style
Basic Syntax

Both HTML and CSS follow a specific syntax that must be respected for the browser to render a page correctly.

In HTML, every element should be properly opened and closed, and nested elements should not overlap incorrectly.

<div class="container"></div>

In CSS, every declaration must end with a semicolon, and every rule must be wrapped in curly braces.

p { margin: 0; padding: 10px; }

Following consistent syntax makes your code easier to read, debug, and maintain over time.

Common Terms

Here are a few common terms you will encounter frequently while working with HTML and CSS.

  • Element - a single unit of HTML content, such as a paragraph or heading
  • Attribute - extra information added to an HTML tag
  • Selector - a pattern used in CSS to select the elements you want to style

Understanding these terms will help you read documentation and communicate more clearly with other developers.
